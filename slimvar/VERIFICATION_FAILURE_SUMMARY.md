## 为什么失败？

### 理论错误

```python
# 错误假设：
scale_mul接近 → attention pattern相似

# 实际情况：
attention = softmax(scale_mul * (Q @ K^T))
                    ↑           ↑
                  标量      680×680矩阵
                            主导因素！

# 结果：
即使scale_mul相同，Q@K^T不同 → attention完全不同
```

### 类比理解

**聚类假设**就像：
```
错误：两个人用同样倍数的放大镜 → 他们在看同样的东西
正确：放大倍数相同，但他们看着地图的不同位置
```

### 当前推荐策略

**🏆 首选: 策略2（方差条件剪枝）**
```python
def variance_conditional_pruning(scale_mul, num_prune, layer_variance, threshold):
    if layer_variance > threshold:
        # 高方差层：剪低scale（通才冗余）
        return torch.argsort(scale_mul)[:num_prune]
    else:
        # 低方差层：剪高scale（专家冗余）
        return torch.argsort(scale_mul, descending=True)[:num_prune]
```

**特点**:
- ✅ 不依赖聚类假设
- ✅ 理论独立有效
- ✅ 实现简单
- ✅ 置信度85%
