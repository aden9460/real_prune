## 1. 理论基础与动机

### 1.1 问题背景

当前的 VAR 模型剪枝使用 **全局 SlimGPT 补偿**：当剪掉某个 attention head 后，所有剩余的 heads（无论功能类型）都会调整权重来补偿被剪掉的 head。

**核心问题**：不同的 attention heads 有不同的关注模式（attention pattern），全局补偿可能导致：
- **功能不匹配**：专家型 head（关注特定位置）被剪掉后，通才型 head（关注全局）无法有效补偿
- **补偿冲突**：两种类型的 heads 同时调整权重，可能相互干扰
- **重建误差增大**：补偿不精确导致 FID 下降

### 1.2 从 scale_mul 到 attention 分布

**之前的假设（已被验证失败）**：
```
scale_mul 相似 → attention pattern 相似
```

**验证结果**（CLUSTERING_VERIFICATION_RESULTS_ANALYSIS.md）：
- 5/6 层显示 scale_mul 与 pattern 相似度无相关或反相关
- Silhouette score = 0.0（聚类完全失败）
- **原因**：Q@K^T 矩阵（680×680）主导 pattern，scale_mul（1个标量）只控制温度

**新假设（本方案）**：
```
直接用 attention 分数分布特征 → 分为集中型和平缓型 → 组内补偿
```

**理论依据**：
1. **集中型 heads**（Concentrated）：
   - Attention 集中在少数关键 tokens
   - 低 entropy、小 effective span、高 Gini coefficient
   - 功能：提取局部精细特征（如边缘、纹理）

2. **平缓型 heads**（Smooth）：
   - Attention 均匀分布在多个 tokens
   - 高 entropy、大 effective span、低 Gini coefficient
   - 功能：整合全局信息（如语义、结构）

**关键洞察**：
- 集中型 head 被剪掉 → 需要其他集中型 heads 补偿（保持局部关注能力）
- 平缓型 head 被剪掉 → 需要其他平缓型 heads 补偿（保持全局整合能力）
- **跨类型补偿会降低效果**

### 1.3 与之前失败方法的区别

| 方面 | 之前的 scale_mul 聚类 | 本方案 |
|------|---------------------|--------|
| **假设** | scale_mul → pattern | attention 分布 → 功能类型 |
| **验证状态** | 已证伪 | 待验证（理论合理） |
| **分组依据** | 单一标量（scale_mul） | 三维特征（entropy, span, Gini） |
| **分组单位** | 试图按 head 聚类 | 按 head 聚类 |
| **补偿范围** | 无（仅分析） | 组内补偿 |
| **目标** | 发现冗余 heads | 匹配补偿需求 |

**本方案的优势**：
1. 不依赖 scale_mul（已知不可靠）
2. 直接测量真实 attention 行为
3. 用多维特征（更稳健）
4. 不假设 pattern 相似，只假设功能需求相似

## 2. 核心创新点

### 2.1 创新 1：基于真实 Attention 分布的分组

**传统方法**：
```
基于权重范数、梯度、或者启发式规则
```

**本方案**：
```
运行模型 → 提取真实 attention weights → 计算分布特征 → 数据驱动聚类
```

### 2.2 创新 2：组内 SlimGPT 补偿

**传统 SlimGPT**（全局补偿）：
```python
# 所有剩余 heads 都参与补偿
W[:, remaining_columns] -= Error @ Hinv[:, remaining_columns]
```

**本方案**（组内补偿）：
```python
# 只有同组的 heads 参与补偿
W[:, remaining_in_group] -= Error @ Hinv_group[:, remaining_in_group]
```

**数学意义**：
- 全局补偿：最小化 ||f_pruned(x) - f_original(x)||² 在所有权重空间
- 组内补偿：最小化相同目标，但约束补偿权重在功能相似的子空间

### 2.3 创新 3：不修改模型文件的提取方法

参考 `verify_scale_concentration.py` 的做法：
- 使用 monkey patch 和 forward hook
- 强制使用 `slow_attn` 路径
- 运行时拦截 attention 计算

**优势**：
- 不污染原始模型代码
- 易于调试和恢复
- 可以在不同模型上复用

### 3.2 Attention 提取：不修改模型文件

**参考**：`verify_scale_concentration.py` 的 `AttentionMapExtractor` 类（行196-384）

**核心思路**：
```python
class AttentionMapExtractor:
    def __init__(self, model, layer_idx):
        self.target_attn = model.blocks[layer_idx].attn

        # 强制使用 slow_attn（可以 hook）
        self.target_attn.using_flash = False
        self.target_attn.using_xform = False

    def _compute_slow_attn_with_capture(self, query, key, value, scale, attn_mask):
        """拦截 attention 计算"""
        # 标准 attention 计算
        attn_scores = query.mul(scale) @ key.transpose(-2, -1)
        if attn_mask is not None:
            attn_scores += attn_mask
        attn_weights = F.softmax(attn_scores, dim=-1)  # [B, H, L, L]

        # ★ 关键：保存 attention weights
        self.attention_maps.append(attn_weights.detach().cpu())

        return attn_weights @ value

    def extract(self, inputs, use_teacher_forcing=False, input_tokens=None):
        """运行模型并捕获 attention"""
        # Monkey patch forward 函数
        original_forward = self.target_attn.forward

        def patched_forward(x, attn_bias):
            B, L, C = x.shape

            # 手动执行 QKV projection（复制原始逻辑）
            qkv = F.linear(x, self.target_attn.mat_qkv.weight,
                          torch.cat([self.target_attn.q_bias,
                                   self.target_attn.zero_k_bias,
                                   self.target_attn.v_bias]))
            qkv = qkv.view(B, L, 3, self.target_attn.num_heads, 64)
            q, k, v = qkv.permute(2, 0, 3, 1, 4).unbind(0)  # [B, H, L, 64]

            # L2 normalize（如果模型使用）
            if self.target_attn.attn_l2_norm:
                scale_mul = self.target_attn.scale_mul_1H11.clamp_max(
                    self.target_attn.max_scale_mul
                ).exp()
                q = F.normalize(q, dim=-1).mul(scale_mul)
                k = F.normalize(k, dim=-1)

            # ★ 使用我们的捕获版本
            oup = self._compute_slow_attn_with_capture(
                q, k, v, self.target_attn.scale, attn_bias
            ).transpose(1, 2).reshape(B, L, C)

            return self.target_attn.proj_drop(self.target_attn.proj(oup))

        # 临时替换
        self.target_attn.forward = patched_forward
        try:
            with torch.no_grad():
                if use_teacher_forcing:
                    # 使用真实图片 tokens（更准确）
                    self._forward_with_tokens(inputs, input_tokens)
                else:
                    # Autoregressive 生成
                    self.model.autoregressive_infer_cfg(...)
        finally:
            # 恢复原始 forward
            self.target_attn.forward = original_forward

        return torch.cat(self.attention_maps, dim=0)  # [B, H, L, L]
```

**关键点**：
1. **不修改 basic_var.py**：通过 monkey patch 实现
2. **强制 slow_attn**：flash attention 和 xformers 无法 hook
3. **Teacher Forcing 模式**：使用真实图片编码的 tokens，attention 更接近实际推理

### 3.3 集中度指标计算

**指标 1：Shannon Entropy（熵）**

```python
def compute_attention_entropy(attention_weights):
    """
    计算 attention 分布的熵

    Args:
        attention_weights: [batch, num_heads, seq, seq]

    Returns:
        entropy_per_head: [num_heads] 每个 head 的平均熵

    解释:
        熵 = -Σ p*log(p)
        - 低熵（如 1.5）→ 集中型（少数 tokens 占主导）
        - 高熵（如 5.0）→ 平缓型（均匀分布）
        - 最大值 = log(seq_len)（完全均匀）
    """
    batch, num_heads, seq, _ = attention_weights.shape
    entropies = []

    for head_idx in range(num_heads):
        head_attn = attention_weights[:, head_idx, :, :]  # [batch, seq, seq]

        # 计算每个 query position 的熵
        entropies_per_query = []
        for b in range(batch):
            for q in range(seq):
                attn_dist = head_attn[b, q, :]  # [seq]

                # Shannon entropy
                entropy = -torch.sum(attn_dist * torch.log(attn_dist + 1e-10))
                entropies_per_query.append(entropy.item())

        # 平均所有 queries
        entropies.append(np.mean(entropies_per_query))

    return torch.tensor(entropies)
```

**指标 2：Effective Span（有效范围）**

```python
def compute_effective_span(attention_weights, threshold=0.9):
    """
    计算覆盖 threshold（默认90%）权重所需的 token 数

    解释:
        - 小 span（如 5）→ 集中型（关注 5 个 tokens 即占 90% 权重）
        - 大 span（如 100）→ 平缓型（需要 100 个 tokens 才占 90%）
        - 最小值 = 1（完全集中）
        - 最大值 = seq_len（完全均匀）
    """
    batch, num_heads, seq, _ = attention_weights.shape
    spans = []

    for head_idx in range(num_heads):
        head_attn = attention_weights[:, head_idx, :, :]

        spans_per_query = []
        for b in range(batch):
            for q in range(seq):
                attn_dist = head_attn[b, q, :]

                # 按权重降序排序
                sorted_attn, _ = torch.sort(attn_dist, descending=True)

                # 累积和达到 threshold 的位置数
                cumsum = torch.cumsum(sorted_attn, dim=0)
                span = torch.sum(cumsum < threshold).item() + 1
                spans_per_query.append(span)

        spans.append(np.mean(spans_per_query))

    return torch.tensor(spans)
```

**指标 3：Gini Coefficient（基尼系数）**

```python
def compute_gini_coefficient(attention_weights):
    """
    计算分布不均匀程度

    解释:
        - 高 Gini（如 0.8）→ 集中型（不均匀，少数占大部分）
        - 低 Gini（如 0.2）→ 平缓型（均匀分布）
        - 范围: [0, 1]
    """
    batch, num_heads, seq, _ = attention_weights.shape
    gini_coeffs = []

    for head_idx in range(num_heads):
        head_attn = attention_weights[:, head_idx, :, :]

        ginis = []
        for b in range(batch):
            for q in range(seq):
                attn_dist = head_attn[b, q, :].cpu().numpy()

                # 排序
                sorted_attn = np.sort(attn_dist)
                n = len(sorted_attn)

                # Gini 公式
                cumsum = np.cumsum(sorted_attn)
                gini = (n + 1 - 2 * np.sum((n - np.arange(n)) * sorted_attn) / cumsum[-1]) / n
                ginis.append(gini)

        gini_coeffs.append(np.mean(ginis))

    return torch.tensor(gini_coeffs)
```

### 3.4 K-means 聚类

```python
def cluster_heads_by_concentration(entropies, spans, ginis, k=2):
    """
    用 K-means 将所有 heads 分为 k 组

    Args:
        entropies: [num_total_heads] 所有层的 heads
        spans: [num_total_heads]
        ginis: [num_total_heads]
        k: 聚类数（默认2：集中组、平缓组）

    Returns:
        head_groups: dict, {"layer_0_head_3": 0, "layer_1_head_5": 1, ...}
        cluster_centers: 聚类中心
        silhouette: Silhouette score（聚类质量，期望 > 0.3）
    """
    from sklearn.cluster import KMeans
    from sklearn.preprocessing import StandardScaler
    from sklearn.metrics import silhouette_score

    # 归一化特征（重要！不同指标尺度不同）
    scaler = StandardScaler()
    features = np.stack([
        entropies.numpy(),
        spans.numpy(),
        ginis.numpy()
    ], axis=1)  # [num_heads, 3]

    features_normalized = scaler.fit_transform(features)

    # K-means 聚类
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=20)
    labels = kmeans.fit_predict(features_normalized)

    # 评估聚类质量
    silhouette = silhouette_score(features_normalized, labels)

    # 构建 head_groups dict
    head_groups = {}
    num_layers = len(entropies) // 16  # 假设每层 16 heads

    for idx, label in enumerate(labels):
        layer_idx = idx // 16
        head_idx = idx % 16
        head_groups[f"layer_{layer_idx}_head_{head_idx}"] = int(label)

    # 分析聚类中心（确定哪个组是集中型）
    centers = scaler.inverse_transform(kmeans.cluster_centers_)
    # Group 0 vs Group 1: 比较平均 entropy
    if centers[0, 0] < centers[1, 0]:  # Group 0 熵更低
        group_mapping = {0: "Concentrated", 1: "Smooth"}
    else:
        group_mapping = {1: "Concentrated", 0: "Smooth"}

    print(f"Silhouette Score: {silhouette:.3f}")
    print(f"Group 0: {group_mapping[0]}, {np.sum(labels==0)} heads")
    print(f"Group 1: {group_mapping[1]}, {np.sum(labels==1)} heads")

    return head_groups, centers, silhouette
```

## 4. 补偿机制深度解析

### 4.1 SlimGPT 数学原理

**问题定义**：

给定一个线性层 `y = Wx + b`，我们想剪掉一些列（对应某些 attention heads），同时最小化输出的变化。

**目标函数**：

```
min ||W_pruned @ x - W_original @ x||²
```

其中：
- `W_original`: 原始权重 `[out_features, in_features]`
- `W_pruned`: 剪枝后的权重（某些列设为0或删除）
- `x`: 输入激活（从校准数据收集）

**SlimGPT 方法**：

1. **收集 Hessian 矩阵**（二阶信息）：

```python
H = Σ(x_i @ x_i^T) / N
```

其中 `x_i` 是第 i 个校准样本的激活。

- 形状：`[in_features, in_features]`
- 意义：`H[i,j]` 衡量输入特征 i 和 j 的协方差
- 对角元 `H[i,i]` 大 → 特征 i 的方差大（重要）

2. **选择剪枝列**（贪心算法）：

对每一列 `c`，计算剪掉它的"误差成本"：

```python
error_c = Σ(W[:, c]² / H[c, c])
```

- 分子 `W[:, c]²`：该列权重的平方和（该列的"贡献"）
- 分母 `H[c, c]`：该列对应输入特征的方差（该列的"可补偿性"）
- **直觉**：选择权重小且输入方差大的列（容易补偿）

3. **补偿剩余列**（关键！）：

剪掉列 `c` 后，更新剩余列的权重：

```python
# 计算 Hessian 的逆
H_inv = torch.cholesky_inverse(torch.linalg.cholesky(H))

# 对于每个剪掉的列 c
Error = W[:, c:c+1]  # 被剪掉列的权重

# 更新所有剩余列
W[:, remaining_cols] -= Error @ H_inv[c, remaining_cols]
```

**数学推导**（简化版）：

目标：最小化 `||W_new @ x - W_old @ x||²`

展开：
```
= ||W_new @ x - (W_new + Error_col) @ x||²
= ||Error_col @ x||²
= Error_col^T @ (x @ x^T) @ Error_col
= Error_col^T @ H @ Error_col
```

最优解（拉格朗日乘子法）：
```
W_new = W_old - Error @ H_inv @ ...
```

**核心洞察**：
- `H_inv[c, j]` 衡量列 c 和列 j 的"补偿关系"
- 如果 `H_inv[c, j]` 大 → 列 j 可以很好地补偿列 c
- 补偿权重由 Hessian 的逆矩阵自动决定（数据驱动）

### 4.2 全局补偿 vs 组内补偿

**全局补偿（当前方法）**：

```python
def struct_prune_global(self, sparsity, headsize=64):
    """
    全局补偿：所有剩余 heads 都参与补偿
    """
    num_heads = self.in_features // headsize
    n_prune = int(num_heads * sparsity)

    # 1. 使用全局 Hessian
    H = self.H  # [in_features, in_features]
    H_inv = torch.cholesky_inverse(torch.linalg.cholesky(H))

    # 2. 计算所有列的误差
    errors = torch.zeros(num_heads)
    for h in range(num_heads):
        cols = range(h * headsize, (h+1) * headsize)
        W_head = self.W[:, cols]  # [out, headsize]
        H_head = H[cols, cols]    # [headsize, headsize]

        # 误差 = Σ(W² / diag(H))
        errors[h] = torch.sum(W_head ** 2 / torch.diag(H_head))

    # 3. 选择最小误差的 heads 剪掉
    prune_heads = torch.argsort(errors)[:n_prune]

    # 4. 全局补偿
    for h in prune_heads:
        cols = range(h * headsize, (h+1) * headsize)
        Error = self.W[:, cols]  # [out, headsize]

        # ★ 关键：更新 ALL 剩余列
        remaining_cols = [c for c in range(self.in_features)
                         if c not in cols]

        self.W[:, remaining_cols] -= Error @ H_inv[cols, :][:, remaining_cols]

    return prune_heads
```

**问题**：

假设我们剪掉一个**集中型 head**（关注局部特征），全局补偿会：
1. 让**其他集中型 heads** 调整权重（✓ 合理）
2. 让**平缓型 heads** 也调整权重（✗ 不合理）

为什么平缓型 heads 补偿集中型 heads 不合理？
- 平缓型 heads 的 Q、K 投影学习的是"全局注意力"
- 强行让它们补偿"局部注意力"会破坏其功能
- 类似于让"广角镜头"补偿"望远镜"的功能

**组内补偿（本方案）**：

```python
def struct_prune_grouped(self, sparsity, head_groups, layer_idx, headsize=64):
    """
    组内补偿：只有同组的 heads 参与补偿

    Args:
        sparsity: 全局剪枝率（如 0.2）
        head_groups: dict, {"layer_X_head_Y": group_id}
        layer_idx: 当前层索引
        headsize: 每个 head 的通道数（默认64）

    Returns:
        pruned_heads: list of pruned head indices
    """
    num_heads = self.in_features // headsize

    # 1. 按组分离 heads
    group_0_heads = []
    group_1_heads = []

    for h in range(num_heads):
        key = f"layer_{layer_idx}_head_{h}"
        group_id = head_groups.get(key, 0)  # 默认组0

        if group_id == 0:
            group_0_heads.append(h)
        else:
            group_1_heads.append(h)

    print(f"  Layer {layer_idx}: Group 0 (Concentrated) = {len(group_0_heads)} heads")
    print(f"  Layer {layer_idx}: Group 1 (Smooth) = {len(group_1_heads)} heads")

    # 2. 对每个组分别剪枝和补偿
    all_pruned_heads = []

    for group_id, heads_in_group in enumerate([group_0_heads, group_1_heads]):
        if len(heads_in_group) == 0:
            continue

        # 2.1 计算该组需要剪掉的 head 数量（按比例）
        n_prune_group = int(len(heads_in_group) * sparsity)
        if n_prune_group == 0:
            print(f"    Group {group_id}: Too few heads, skip pruning")
            continue

        print(f"    Group {group_id}: Pruning {n_prune_group}/{len(heads_in_group)} heads")

        # 2.2 提取组内的列索引
        group_cols = []
        for h in heads_in_group:
            group_cols.extend(range(h * headsize, (h+1) * headsize))
        group_cols = sorted(group_cols)

        # 2.3 构建组内的 Hessian 子矩阵（关键！）
        H_group = self._extract_hessian_submatrix(group_cols)
        # H_group: [len(group_cols), len(group_cols)]

        # 2.4 在组内选择剪枝的 heads（使用组内 Hessian）
        pruned_heads_in_group = self._select_prune_heads_in_group(
            heads_in_group, H_group, n_prune_group, headsize
        )

        # 2.5 组内补偿（核心！）
        self._compensate_within_group(
            pruned_heads_in_group, heads_in_group,
            group_cols, H_group, headsize
        )

        all_pruned_heads.extend(pruned_heads_in_group)

    return sorted(all_pruned_heads)
```

### 4.3 组内 Hessian 构建

**关键问题**：如何从全局 Hessian `H` 中提取组内 Hessian `H_group`？

**方法 1：子矩阵提取**（推荐）

```python
def _extract_hessian_submatrix(self, group_cols):
    """
    从全局 Hessian 提取组内子矩阵

    Args:
        group_cols: list of column indices in this group
            例如: [0,1,2,...,63, 128,129,...,191] (head 0 和 head 2 的列)

    Returns:
        H_group: [len(group_cols), len(group_cols)]

    数学意义:
        H_global[i, j] = Σ(x[i] * x[j]) / N
        H_group 只保留 group 内列的协方差
    """
    # 直接索引子矩阵
    H_group = self.H[group_cols, :][:, group_cols]

    # 验证正定性（Cholesky 分解需要）
    try:
        _ = torch.linalg.cholesky(H_group)
    except RuntimeError:
        # 如果不正定，添加正则化
        eps = 1e-6
        H_group += eps * torch.eye(H_group.shape[0], device=H_group.device)
        print(f"    Warning: Added regularization {eps} to H_group")

    return H_group
```

**方法 2：重新计算**（精确但慢）

```python
def _recompute_hessian_for_group(self, group_cols, activations):
    """
    从激活重新计算组内 Hessian

    优点: 更精确（考虑组内激活的独立性）
    缺点: 需要重新访问激活数据（慢）
    """
    H_group = torch.zeros(len(group_cols), len(group_cols), device=self.H.device)

    for x in activations:  # x: [batch, in_features]
        x_group = x[:, group_cols]  # [batch, len(group_cols)]
        H_group += x_group.T @ x_group

    H_group /= len(activations)
    return H_group
```

**推荐**：使用方法1（子矩阵提取），因为：
- 更快（O(1)索引 vs O(N)重计算）
- 数学上等价（Hessian 的子矩阵就是子空间的 Hessian）
- 实践中足够精确

### 4.4 组内剪枝选择

```python
def _select_prune_heads_in_group(self, heads_in_group, H_group, n_prune, headsize):
    """
    在组内选择要剪掉的 heads

    策略: 选择"组内误差"最小的 heads

    Args:
        heads_in_group: list of head indices in this group
        H_group: Hessian submatrix for this group
        n_prune: number of heads to prune
        headsize: channels per head

    Returns:
        pruned_heads: list of head indices (global)
    """
    errors = []

    for local_idx, global_head_idx in enumerate(heads_in_group):
        # 该 head 在组内的列范围
        local_cols = range(local_idx * headsize, (local_idx+1) * headsize)

        # 提取该 head 的权重（从全局 W）
        global_cols = range(global_head_idx * headsize, (global_head_idx+1) * headsize)
        W_head = self.W[:, global_cols]  # [out, headsize]

        # 提取该 head 的组内 Hessian
        H_head = H_group[local_cols, :][:, local_cols]  # [headsize, headsize]

        # 计算误差（标准 SlimGPT 公式）
        error = torch.sum(W_head ** 2 / torch.diag(H_head).clamp(min=1e-8))
        errors.append(error.item())

    # 选择误差最小的 n_prune 个 heads
    sorted_indices = np.argsort(errors)
    pruned_local_indices = sorted_indices[:n_prune]

    # 映射回全局 head 索引
    pruned_heads = [heads_in_group[i] for i in pruned_local_indices]

    return pruned_heads
```

### 4.5 组内补偿实现

**核心公式**：

```
W[:, remain_in_group] -= Error @ H_inv_group[:, remain_cols_in_group]
```

**完整实现**：

```python
def _compensate_within_group(self, pruned_heads, heads_in_group,
                             group_cols, H_group, headsize):
    """
    组内补偿：只更新组内剩余 heads 的权重

    数学原理:
        剪掉 head c 后，最优补偿为：
        ΔW[:, j] = -W[:, c] @ H_inv[c, j]

        组内约束：只补偿 j ∈ heads_in_group

    Args:
        pruned_heads: list of pruned head indices (global)
        heads_in_group: list of all heads in this group (global)
        group_cols: list of column indices in this group
        H_group: Hessian submatrix [len(group_cols), len(group_cols)]
        headsize: channels per head
    """
    # 1. 计算 H_group 的逆（Cholesky 分解）
    try:
        L = torch.linalg.cholesky(H_group)
        H_inv_group = torch.cholesky_inverse(L)
    except RuntimeError as e:
        print(f"    Error: Cholesky failed for H_group: {e}")
        print(f"    Eigenvalues: {torch.linalg.eigvalsh(H_group)[:5]}")
        return  # 跳过补偿

    # 2. 确定剩余的 heads（在组内）
    remaining_heads = [h for h in heads_in_group if h not in pruned_heads]

    if len(remaining_heads) == 0:
        print(f"    Warning: No remaining heads in group!")
        return

    print(f"    Remaining heads in group: {len(remaining_heads)}")

    # 3. 对每个被剪掉的 head 进行补偿
    for pruned_head in pruned_heads:
        # 3.1 该 head 在全局和组内的列索引
        global_cols_pruned = list(range(pruned_head * headsize,
                                       (pruned_head+1) * headsize))

        # 找到这些列在 group_cols 中的位置
        local_cols_pruned = [group_cols.index(c) for c in global_cols_pruned]

        # 3.2 提取该 head 的权重（误差项）
        Error = self.W[:, global_cols_pruned]  # [out, headsize]

        # 3.3 对组内每个剩余 head 进行补偿
        for remain_head in remaining_heads:
            # 剩余 head 在全局和组内的列索引
            global_cols_remain = list(range(remain_head * headsize,
                                           (remain_head+1) * headsize))
            local_cols_remain = [group_cols.index(c) for c in global_cols_remain]

            # ★ 核心：计算补偿权重
            # H_inv_group[local_pruned, local_remain]: [headsize, headsize]
            compensation_matrix = H_inv_group[local_cols_pruned, :][:, local_cols_remain]
            # compensation_matrix: [headsize, headsize]

            # 更新剩余 head 的权重
            # ΔW = -Error @ compensation_matrix
            delta_W = -Error @ compensation_matrix  # [out, headsize]

            self.W[:, global_cols_remain] += delta_W

    print(f"    ✓ Compensation complete for {len(pruned_heads)} pruned heads")
```

**关键点解释**：

1. **为什么是减法**？
   ```
   原输出: y = W_original @ x
         = (W_remain + W_pruned) @ x

   剪枝后: y' = W_remain @ x

   误差: Δy = y - y' = W_pruned @ x

   补偿目标: 最小化 ||Δy||²
   最优解: W_remain += (-W_pruned @ H_inv[pruned, remain])
   ```

2. **为什么需要 H_inv**？
   - 不同列之间的激活是相关的（通过 H 衡量）
   - 直接把 W_pruned 加到 W_remain 是错误的（忽略相关性）
   - H_inv 提供了最优的线性组合系数

3. **组内 vs 全局的区别**：
   ```python
   # 全局补偿（旧方法）
   for remain_col in ALL_remaining_columns:
       W[:, remain_col] += delta  # 所有列都更新

   # 组内补偿（新方法）
   for remain_col in remaining_columns_in_SAME_GROUP:
       W[:, remain_col] += delta  # 只更新同组列
   ```

### 4.6 补偿效果的理论分析

**定理**（非正式）：

假设 attention heads 分为两类（集中型和平缓型），它们的激活子空间正交或弱相关，则：

```
Reconstruction_Error(组内补偿) ≤ Reconstruction_Error(全局补偿)
```

**直觉解释**：

1. **子空间投影**：
   - 集中型 heads 的激活张成一个子空间 `S_conc`
   - 平缓型 heads 的激活张成一个子空间 `S_smooth`
   - 如果 `S_conc ⊥ S_smooth`（正交），则它们不能互相补偿

2. **信息论角度**：
   - 集中型 heads 传递"高频信息"（局部细节）
   - 平缓型 heads 传递"低频信息"（全局结构）
   - 让低频 heads 补偿高频信息会失真

3. **优化角度**：
   - 全局补偿：在整个权重空间 `R^d` 中搜索补偿方向
   - 组内补偿：在功能相似子空间 `R^{d/2}` 中搜索
   - 约束优化可能更优（类似正则化效果）

**实验验证**（需要做）：

1. 测量组间 Hessian 的相关性：
   ```python
   H_cross = H[group0_cols, :][:, group1_cols]
   correlation = torch.norm(H_cross) / torch.norm(H)
   ```
   期望：`correlation < 0.3`（弱相关）

2. 测量补偿重建误差：
   ```python
   error_global = ||output_after_global_compensation - output_original||
   error_grouped = ||output_after_grouped_compensation - output_original||
   ```
   期望：`error_grouped < error_global`

## 5. 关键澄清：O矩阵补偿的理论重审

### 5.1 补偿对象的澄清

**关键误解（需要纠正）**：

在 v1.0 版本中，我们隐式假设对 QKV 层的激活做补偿。但**实际上**，SlimGPT 补偿的是：

```python
# VAR Attention 的完整前向传播
x: [B, L, hidden_dim]  # 输入

# Step 1: QKV projection
Q = x @ W_Q  # [B, L, num_heads * head_dim]
K = x @ W_K
V = x @ W_V

# Step 2: Multi-head attention
attn_weights = softmax(Q @ K.T / scale)  # [B, num_heads, L, L]
attn_out = attn_weights @ V  # [B, num_heads, L, head_dim]

# Step 3: Concatenate heads
attn_out_concat = concat(attn_out, dim=head)  # [B, L, num_heads * head_dim]
# ★ attn_out_concat = [head_0_output | head_1_output | ... | head_15_output]

# Step 4: ★★★ Output projection（这里做补偿！）★★★
output = attn_out_concat @ W_O + b_O  # [B, L, hidden_dim]
```

**SlimGPT 实际补偿的层**：

```
输入：attn_out_concat  # 所有 heads 的输出拼接
权重：W_O  # Output projection matrix [num_heads * head_dim, hidden_dim]

剪枝：删除 W_O 的某些列（对应某些 heads）
补偿：调整 W_O 的剩余列
```

### 5.2 Hessian 的真实含义

**之前的理解（错误）**：

```
H[i, j] = E[x[i] · x[j]]  # 输入 x 的协方差
```

**实际情况（正确）**：

```
H[i, j] = E[attn_out[i] · attn_out[j]]

其中 attn_out = [head_0_output, head_1_output, ..., head_15_output] 拼接

展开：
head_k_output = attention_weights[k] @ V  # [B, L, head_dim]

所以：
H[i, j] = E[(attn_i @ V) · (attn_j @ V)^T]
        = E[attn_i @ (V @ V^T) @ attn_j^T]
```

**关键区别**：

- v1.0 理解：H 衡量**输入特征**的相关性
- 实际情况：H 衡量**不同 heads 输出**的相关性

### 5.3 共享 V 矩阵的影响（最大障碍！）

**核心问题**：所有 heads 共享同一个 V projection

```python
V = x @ W_V  # 所有 heads 共享

head_0_output = attn_0 @ V  # 加权组合 V 的行
head_1_output = attn_1 @ V  # 也是加权组合 V 的行

# 即使 attn_0 和 attn_1 完全不同
# 输出仍然是相同矩阵 V 的不同线性组合
# → 必然有相关性！
```

**数学分析**：

```
H[i, j] = E[(attn_i @ V) @ (attn_j @ V)^T]

展开：
= E[Σ_k Σ_l attn_i[k] · attn_j[l] · V[k] · V[l]^T]

关键：V[k] 和 V[l] 的内积（V@V^T 的元素）

如果 V 学习到的表示是密集的（所有 tokens 都相关）：
→ 所有 heads 的输出都相关
→ H 不是块对角！
```

**例子**：

```
V: [680, 64]  # 680 个 tokens，每个 64 维

Head 0（集中型）:
  output = 0.9*V[10] + 0.1*V[20]  # 只关注 2 个 tokens

Head 1（平缓型）:
  output = (1/680) * Σ V[i]  # 关注所有 tokens（平均）

问题：
如果 V[10] 和 V[20] 与其他 V[i] 相关（通常会相关！）
→ head_0_output 和 head_1_output 相关
→ H[0, 1] ≠ 0
→ 块对角假设不成立
```

### 5.4 块对角假设的新条件

**原假设**（v1.0，过于乐观）：

```
不同 attention patterns → 输出正交 → H 块对角
```

**修正后的假设**（v2.0，更严格）：

H 块对角需要**同时满足**：

1. **Attention patterns 分化**：
   - 集中型 heads 关注不同位置
   - 平缓型 heads 关注全局

2. **V 矩阵有频域分离**：
   ```
   V = [V_low_freq | V_high_freq]

   集中型 heads 主要使用 V_high_freq
   平缓型 heads 主要使用 V_low_freq

   且 V_low_freq ⊥ V_high_freq
   ```

3. **V@V^T 有块状结构**：
   ```
   V @ V^T ≈ [局部相关块    0     ]
             [    0      全局相关块]
   ```

**现实性评估**：

条件 1：✓ 可能（已有文献支持 attention 分化）
条件 2：❓ 不确定（需要 V 学习到特定结构）
条件 3：✗ 不太可能（Transformer 的全局感受野）

**概率估计**：H 确实块对角的概率 < 30%

### 5.5 O 矩阵的设计意图

**O 矩阵的作用**：

```python
output = attn_out_concat @ W_O

W_O: [num_heads * head_dim, hidden_dim]
```

**设计目的**：
- **混合**所有 heads 的信息
- 将多头输出投影回统一的表示空间
- 不是为了"分离"不同类型的 heads

**文献证据**：

论文："Are Sixteen Heads Really Better than One?" (NeurIPS 2019)

发现：
- 不同 heads 学习到**不同的 attention patterns**（✓）
- 但 heads 的**输出表示**高度冗余（✗ 对我们不利）
- 很多 heads 可以被剪掉而不影响性能
- 说明输出空间有重叠

**结论**：O 矩阵的设计与"块对角 Hessian"的假设相矛盾

### 5.6 理论基础的削弱

**v1.0 的理论**：

```
If H 块对角 → 组内补偿最优
支持证据：子空间正交、信息论
```

**v2.0 的修正**：

```
H 块对角的条件非常严格（需要 V 有特殊结构）
即使 attention patterns 分化，共享 V 导致输出耦合
O 矩阵设计的目的就是混合所有 heads

→ H 很可能 NOT 块对角
→ 组内补偿不一定优于全局补偿
```

**诚实评估**：

| 方面 | v1.0 评估 | v2.0 修正 |
|------|----------|----------|
| 理论严谨性 | ⭐⭐⭐ | ⭐⭐ |
| 成功概率 | 50-60% | 20-30% |
| 块对角假设 | 合理 | 很难成立 |
| 预期改进 | 5-10% | 0-3% |

### 6.2 为什么比 v1.0 更悲观？

2. **共享 V 是强约束**：

   - 没见过成功的 O 矩阵分组补偿案例

#!/usr/bin/env python3
"""
提取所有层的 attention weights 用于聚类分析
基于 verify_scale_concentration.py 的方法
"""

import torch
import numpy as np
from tqdm import tqdm
import argparse

# 复用 AttentionMapExtractor（从 verify_scale_concentration.py 196-384行）
from verify_scale_concentration import (
    AttentionMapExtractor,
    load_var_model,
    prepare_calibration_data
)

def extract_all_layers_attention(model, calibration_labels, calibration_tokens,
                                 use_teacher_forcing=True):
    """
    提取所有层的 attention weights

    Returns:
        attention_dict: {layer_idx: attention_weights [B, H, L, L]}
    """
    num_layers = len(model.blocks)
    attention_dict = {}

    for layer_idx in tqdm(range(num_layers), desc="Extracting attention"):
        extractor = AttentionMapExtractor(model, layer_idx)

        try:
            attention_weights = extractor.extract(
                calibration_labels,
                use_teacher_forcing=use_teacher_forcing,
                input_tokens=calibration_tokens
            )
            attention_dict[layer_idx] = attention_weights.cpu()
            extractor.restore()
        except Exception as e:
            print(f"Failed at layer {layer_idx}: {e}")
            continue

    return attention_dict

def main(args):
    # 加载模型
    vae, var = load_var_model(args.model_depth, args.vae_ckpt, args.var_ckpt)

    # 准备数据

        vae, args.num_samples, args.imagenet_dir
    )

    # 提取 attention
    attention_dict = extract_all_layers_attention(

    )

    # 保存
    torch.save(attention_dict, f'attention_weights_d{args.model_depth}.pt')
    print(f"Saved to attention_weights_d{args.model_depth}.pt")

#### Step 1.2: 创建分析工具 `analyze_attention_clustering.py`

```python
#!/usr/bin/env python3
"""
分析 attention 分布并聚类
"""

import torch
import numpy as np
import json
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt
import seaborn as sns

# 复用集中度计算函数（从 verify_scale_concentration.py 390-514行）
from verify_scale_concentration import (
    compute_attention_entropy,
    compute_effective_span,
    compute_gini_coefficient
)

def compute_all_metrics(attention_dict):
    """计算所有 heads 的集中度指标"""
    all_entropies = []
    all_spans = []
    all_ginis = []
    head_info = []

    for layer_idx, attn_weights in attention_dict.items():
        # attn_weights: [B, H, L, L]
        entropies = compute_attention_entropy(attn_weights)
        spans = compute_effective_span(attn_weights)
        ginis = compute_gini_coefficient(attn_weights)

        num_heads = attn_weights.shape[1]
        for h in range(num_heads):
            all_entropies.append(entropies[h].item())
            all_spans.append(spans[h].item())
            all_ginis.append(ginis[h].item())
            head_info.append({
                'layer': layer_idx,
                'head': h,
                'entropy': entropies[h].item(),
                'span': spans[h].item(),
                'gini': ginis[h].item()
            })

    return np.array(all_entropies), np.array(all_spans), np.array(all_ginis), head_info

def cluster_heads(entropies, spans, ginis, k=2):
    """K-means 聚类"""
    # 归一化特征
    scaler = StandardScaler()
    features = np.stack([entropies, spans, ginis], axis=1)
    features_norm = scaler.fit_transform(features)

    # K-means
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=20)
    labels = kmeans.fit_predict(features_norm)

    # Silhouette score
    silhouette = silhouette_score(features_norm, labels)

    return labels, kmeans.cluster_centers_, silhouette, scaler

def visualize_clustering(entropies, spans, ginis, labels, save_path):
    """t-SNE 可视化"""
    from sklearn.manifold import TSNE

    features = np.stack([entropies, spans, ginis], axis=1)
    features_norm = StandardScaler().fit_transform(features)

    tsne = TSNE(n_components=2, random_state=42)
    embedded = tsne.fit_transform(features_norm)

    plt.figure(figsize=(10, 8))
    scatter = plt.scatter(embedded[:, 0], embedded[:, 1],
                         c=labels, cmap='viridis', alpha=0.6, s=50)
    plt.colorbar(scatter, label='Cluster')
    plt.title('t-SNE Visualization of Head Clustering')
    plt.xlabel('t-SNE 1')
    plt.ylabel('t-SNE 2')
    plt.savefig(save_path, dpi=200, bbox_inches='tight')
    plt.close()

def main():
    # 加载 attention
    attention_dict = torch.load('attention_weights_d16.pt')

    # 计算指标
    print("Computing concentration metrics...")
    entropies, spans, ginis, head_info = compute_all_metrics(attention_dict)

    # 聚类
    print("Clustering...")
    labels, centers, silhouette, scaler = cluster_heads(entropies, spans, ginis, k=2)

    print(f"Silhouette Score: {silhouette:.3f}")
    print(f"Group 0: {np.sum(labels==0)} heads")
    print(f"Group 1: {np.sum(labels==1)} heads")

    # 保存结果
    head_groups = {}
    for i, info in enumerate(head_info):
        key = f"layer_{info['layer']}_head_{info['head']}"
        head_groups[key] = int(labels[i])
        info['group'] = int(labels[i])

    with open('head_groups.json', 'w') as f:
        json.dump(head_groups, f, indent=2)

    with open('head_clustering_metrics.json', 'w') as f:
        json.dump(head_info, f, indent=2)

    # 可视化
    visualize_clustering(entropies, spans, ginis, labels, 'clustering_tsne.png')

    print("Done! Files saved:")
    print("  - head_groups.json")
    print("  - head_clustering_metrics.json")
    print("  - clustering_tsne.png")

if __name__ == "__main__":
    main()
```

## 7. 风险分析与应对

### 7.1 风险 1：聚类质量差

**表现**：Silhouette score < 0.2，两组重叠严重

**原因**：
- Attention 分布本身没有明显的二分性
- 三个指标不足以区分功能类型
- 数据量不足（校准样本太少）

**应对措施**：
1. **增加聚类数**：尝试 k=3 或 k=4
2. **更多特征**：
   - Attention 的局部性（平均距离）
   - Attention 的稀疏性（非零元素比例）
   - Query-Key 相似度分布
3. **层次聚类**：DBSCAN 或 Agglomerative Clustering
4. **手动分析**：可视化后手动标注几个典型 heads

### 7.2 风险 2：某组 heads 数量太少

**表现**：某组只有 3-5 个 heads，剪枝后只剩 1-2 个

**原因**：
- 数据不平衡（大部分 heads 集中在一组）
- 聚类参数不当

**应对措施**：
1. **设置最小组大小**：
   ```python
   if len(group_0_heads) < 5 or len(group_1_heads) < 5:
       print("Warning: Group too small, merging groups")
       # 退化为全局补偿
   ```
2. **不均匀剪枝**：大组剪枝率高，小组剪枝率低
3. **动态调整 k**：如果某组太小，重新聚类

### 7.3 风险 3：组内补偿效果不佳

**表现**：FID(grouped) ≥ FID(baseline)

**原因**：
- 组内 Hessian 条件数太大（不稳定）
- 功能分组不准确
- 剪枝率太高（组内容量不足）

**应对措施**：
1. **软分组（加权补偿）**：
   ```python
   # 不是严格的组内补偿，而是加权
   for remain_head in all_remaining_heads:
       if same_group(remain_head, pruned_head):
           weight = 1.0
       else:
           weight = 0.2  # 允许少量跨组补偿
       W[:, remain_head] += weight * compensation
   ```
2. **正则化 Hessian**：
   ```python
   H_group += lambda * I  # 添加对角正则化
   ```
3. **降低剪枝率**：从 20% 降到 10-15%

### 7.4 风险 4：Teacher Forcing 提取失败

**表现**：内存溢出或速度极慢

**原因**：
- 需要保存完整的 680×680 attention 矩阵
- 多层 × 多样本 × 多 heads = 大显存

**应对措施**：
1. **分批处理**：
   ```python
   batch_size = 8  # 每次只处理 8 个样本
   for batch in tqdm(range(0, num_samples, batch_size)):
       ...
   ```
2. **只保存关键区域**：
   ```python
   # 只保存最大尺度的 attention（256×256）
   if L >= 256:
       self.attention_maps.append(attn_weights[:, :, -256:, -256:])
   ```
3. **使用 FP16**：减少显存占用
4. **降低样本数**：从 100 降到 50
